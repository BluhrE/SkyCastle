# AGENTS.md

## Project
Sky and the Sparkle Crown
Godot 4 project using GDScript

## Rules
- Preserve existing working systems unless the task explicitly requires a change
- Do not rebuild the project from scratch
- Do not refactor the whole codebase unless necessary
- Keep the game scene-based and storybook-like, not website-like
- Keep dialogue readable: black text on white panels unless readability is clearly preserved
- ESC must work consistently across all screens and chapters
- Do not break save/load, map progression, reward flow, or world unlocks
- Keep interactions large and readable for a 4-year-old
- Use the existing art pipeline and asset hooks
- If art is missing, use clean style-consistent placeholders

## When finishing a task
Always provide:
- summary of changed files
- notes on any assumptions
- QA checklist for manual testing
